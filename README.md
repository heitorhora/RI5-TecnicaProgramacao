Prática focada na implementação de classes a partir de um diagrama UML, utilizando composição de objetos e modularização nativa no JavaScript (ES6 Modules).

**Parte 1:** Criação das classes principais (`Empresa`, `Funcionario`, `Endereco` e `Telefone`) com os seus respetivos construtores, garantindo o mapeamento exato dos atributos e a correta relação de dependência entre os objetos (onde uma Empresa possui Funcionários, Endereços, etc.), conforme especificado no diagrama estrutural.

**Parte 2:** Implementação de uma classe descritora (`Descritor`) contendo um método especializado para receber um objeto do tipo empresa e iterar sobre os seus dados. O objetivo é formatar e exibir as informações detalhadas da empresa e dos seus respetivos funcionários diretamente no terminal de forma organizada.
